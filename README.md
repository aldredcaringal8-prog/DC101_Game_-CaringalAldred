# DC101_Game_-CaringalAldred
typing test game Aldred V. Caringal BSCS2I
CodeType is a browser-based typing speed test game designed to improve typing accuracy and speed in a coding-themed environment. Players type randomly generated text while a timer tracks words per minute
HTML5,CSS3,JavaScript
1.Download or clone the project repository
2.Open the project folder
3.Double-click index.html or open it in any modern web browser
4.Start typing to play the game
